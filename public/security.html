MARLON'S WATCHTOWER · SECURITY

This page is for security reports. It is not a support channel.

REPORT A VULNERABILITY

Email marlonbenedicttan@gmail.com with a short description, the affected URL or endpoint, and reproduction steps. Please do not open a public issue for an unfixed vulnerability.

IN SCOPE

  • The public site and its JSON API.
  • Authentication, rate limiting and access-control bypasses.
  • Cross-site scripting, request forgery and injection.
  • Leaked secrets, tokens or private data.

OUT OF SCOPE

  • Denial-of-service, load testing or spam.
  • Social engineering, phishing or physical access.
  • Reports from automated scanners without a working reproduction.
  • Missing headers that do not create a practical exploit.

SAFE HARBOUR

Good-faith research that avoids privacy violations, data destruction and service disruption will not be pursued. Do not access, modify or retain data that is not yours.

NO BUG BOUNTY

This is a personal project. There is no paid bounty. Confirmed reports are credited if you want to be named.
